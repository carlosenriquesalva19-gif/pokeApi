# PokeApi - Android Pokedex App📱

Una aplicación de Android moderna que funciona como una Pokédex, permitiendo a los usuarios explorar el mundo Pokémon. Este proyecto consume la [PokeAPI](https://pokeapi.co/) y está construido siguiendo las mejores prácticas de desarrollo en Android.

## ✨ Características

- **Listado de Pokémon:** Visualización de los 151 Pokémon originales (Kanto) con sus nombres e imágenes.
- **Detalle del Pokémon:** Información detallada que incluye estadísticas base, tipos, altura y peso.
- **Interfaz Moderna:** UI construida íntegramente con **Jetpack Compose**.
- **Navegación Fluida:** Uso de Navigation Compose para transiciones entre la lista y los detalles.
- **Carga de Imágenes:** Integración con Coil para una carga de imágenes eficiente y con caché.

## 🛠️ Stack Tecnológico

- **Lenguaje:** [Kotlin](https://kotlinlang.org/)
- **UI:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **Arquitectura:** MVVM (Model-View-ViewModel) con principios de Clean Architecture.
- **Red:** [Retrofit 2](https://square.github.io/retrofit/) & [Gson](https://github.com/google/gson) para el consumo de la API REST.
- **Carga de Imágenes:** [Coil](https://coil-kt.github.io/coil/)
- **Navegación:** Jetpack Navigation Compose.

## 🚀 Instalación y Uso

1. **Clonar el repositorio:**
   git clone https://github.com/tu-usuario/PokeApi.git

2. **Abrir en Android Studio:**
   Abre el proyecto con la última versión de Android Studio.
3. **Sincronizar con Gradle:**
   Deja que el IDE descargue todas las dependencias necesarias.
4. **Ejecutar:**
   Conecta un dispositivo físico o inicia un emulador y presiona **Run**.

## 📖 API Utilizada

Esta aplicación utiliza la [PokeAPI](https://pokeapi.co/), una API gratuita y abierta que proporciona datos detallados sobre Pokémon.
